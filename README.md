# Malaika-Happy-birthday-
Core Design System & Global Styles (The "Look and Feel"):

- Use a premium dark-mode aesthetic with a deep black/charcoal background.
- Use elegant gradients, soft glowing effects, glassmorphism cards, subtle shadows, and smooth transitions.
- The overall design should feel romantic, luxurious, modern, cinematic, and emotionally warm.
- Use responsive design so the website works perfectly on mobile phones, tablets, and desktops.
- Use modern typography with clear hierarchy and beautiful spacing.
- Add smooth scrolling and polished micro-interactions throughout the experience.
- Use floating particles, glowing hearts, stars, or other subtle decorative elements without making the page look cluttered.
- Animations should be smooth and lightweight enough to work well on mobile devices.
- Avoid external dependencies whenever possible. Everything should be contained inside a single HTML file.

Birthday Person:

Name: Malaika ❤️
Date of Birth: 18 October 2011

The name "Malaika" should appear naturally and beautifully throughout the website.

The birthday date "18 October" should be used in the birthday celebration and countdown sections.

Main Experience:

Create a guided emotional journey rather than a simple static birthday card.

The website should include:

1. A beautiful animated opening screen with Malaika's name.
2. A romantic welcome message.
3. An interactive "Open Your Gift" or "Start the Surprise" button.
4. A heartfelt birthday message written especially for Malaika.
5. A beautiful photo/memory section where photos can be added.
6. Animated hearts, sparkles, particles, and smooth transitions.
7. A special birthday countdown/count-up section connected to 18 October.
8. An interactive surprise/gift section.
9. A final emotional birthday message with a beautiful closing animation.
10. A replay button so the entire experience can be enjoyed again.

Important:

- Keep the entire project self-contained in ONE HTML file.
- Include all HTML, CSS, and JavaScript in the same file.
- Do not require a backend.
- Make all buttons and interactions actually functional.
- Make the website visually impressive on a mobile screen.
- Do not use placeholder text where a meaningful birthday message can be written.
- Make the experience feel personal, genuine, sweet, and memorable.
